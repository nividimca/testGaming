# KPI

## KPI 1 - Comprensione iniziale

- Target: il core loop deve essere comprensibile in meno di `2 minuti`
- Come misurarlo: osservare un primo test interno e verificare se il player capisce movimento, schivata e attacco senza spiegazioni lunghe
- Perche' conta: il gioco vive sulla leggibilita' del conflitto e del pattern

## KPI 2 - Sessione utile

- Target: almeno `15 minuti` di sessione interna cumulata senza perdita di chiarezza del loop
- Come misurarlo: sommare run consecutive durante test manuali
- Perche' conta: il progetto deve reggere brevi iterazioni senza crollare in confusione o attrito

## KPI 3 - Stabilita' minima

- Target: `0 bug blocker` aperti al gate della build interna
- Come misurarlo: usare `bug_log.md` con severita' esplicite
- Perche' conta: il valore del vertical slice dipende dalla possibilita' di provarlo davvero
