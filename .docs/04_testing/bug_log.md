# BUG LOG

Registro unico dei bug aperti, chiusi o mitigati.

## Severita'

- `B1` blocker: impedisce di avviare, giocare o chiudere la run
- `B2` major: rompe parti importanti del loop ma esiste workaround
- `B3` minor: difetto reale ma non blocca la verifica principale

## Campi minimi

- ID
- Date
- Area
- Severity
- Status
- Summary
- Repro
- Owner

## Template

| ID | Date | Area | Severity | Status | Summary | Repro | Owner |
