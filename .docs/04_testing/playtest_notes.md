# PLAYTEST NOTES

Registro dei playtest manuali.

## Come usarlo

- aggiungi la sessione piu' recente in cima
- mantieni note brevi, verificabili e orientate all'azione
- collega eventuali bug a `bug_log.md`

## Template sessione

Date:
Build/Branch:
Tester:
Goal:
Runs:
Observed:
Confusion points:
Bug IDs:
Decision:
Next step:

---

## Checklist minima per sessione

- il player capisce movimento e attacco?
- il loop resta leggibile sotto pressione?
- il fail state e' chiaro?
- il restart e' immediato?
- ci sono bug blocker o soft lock?
