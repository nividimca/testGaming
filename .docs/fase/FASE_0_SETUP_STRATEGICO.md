# FASE 0 — SETUP STRATEGICO

## Stato
**DONE / da validare dall’owner**

## Obiettivo progetto
Creare un gioco completo da 2–4 ore, Windows-first per Steam, mantenendo il progetto mobile-ready a livello architetturale.

## Vincoli

### Tempo
- Disponibilità: 8–10 ore/settimana

### Budget
- Budget totale: 500€
- Uso previsto:
  - asset grafici/audio
  - eventuali tool
  - nessun outsourcing complesso

### Piattaforma
- Target principale: Windows / Steam
- Target secondario: mobile-ready, senza porting mobile immediato

## Priorità
1. Velocità
2. Qualità
3. Costo

## Output atteso
- Gioco completo da 2–4 ore
- Demo/vertical slice giocabile
- Build Windows funzionante

## Project Charter

### Scope iniziale
- Gioco arcade boss-based
- Gameplay semplice e ripetibile
- Focus su schivata, pattern e boss fight
- Grammatica atmosferica coerente dei boss: inizio cupo, colore che cresce tra le fasi

### Anti-scope
Cose da non fare ora:
- Multiplayer
- Open world
- Skill tree complessi
- Grafica custom avanzata
- Mobile nativo completo
- Lore lunga o narrativa complessa

## Rischi principali
1. Scope troppo grande rispetto a 8–10h/settimana
2. Gameplay non definito abbastanza prima della tecnica
3. Over-engineering
4. Pattern poco leggibili
5. Mobile-ready ignorato troppo tardi
